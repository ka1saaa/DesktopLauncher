# DesktopLauncher 使用指南

DesktopLauncher 是一个 Windows 桌面整理工具：用**悬浮球**或**全局热键**唤出手机桌面风格的全屏启动器，把桌面上的快捷方式按自己的分类收好，点图标即可启动。

它只做「索引」：**不移动、不重命名、不删除**桌面上的任何文件。所有整理结果都保存在自己的配置里，随时可以改、可以撤销。

- 适用系统：Windows 10 / 11（x64）
- 界面语言：简体中文
- 不需要管理员权限，不联网

## 1. 安装与启动

### 1.1 系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11，x64 |
| 运行时 | 单文件版自带；源码运行需要 .NET 10 SDK |
| 权限 | 普通用户即可（无需管理员） |
| 网络 | 不需要，程序不发起任何网络请求 |

### 1.2 方式一：从源码运行

```bash
git clone https://github.com/ka1saaa/DesktopLauncher.git
cd DesktopLauncher
dotnet run --project DesktopLauncher -c Release
```

### 1.3 方式二：生成单文件 exe

```bash
dotnet publish DesktopLauncher -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true -o publish
```

生成的 `publish\DesktopLauncher.exe` 约 70 MB，自带 .NET 运行时，可以单独拷到其他 Win10/11 x64 机器上双击运行，无需安装。

> 单文件 exe 首次启动会自解压到临时目录，个别安全软件可能误报，详见 [7.10](#710-安全软件报毒)。

### 1.4 首次启动你会看到什么

1. **托盘图标**：任务栏右下角出现一个蓝色圆形宫格图标；
2. **悬浮球**：屏幕右侧约 40% 高度处出现一个半透明小球（默认开启）；
3. **默认分类**：第一次运行会自动建好「常用」「游戏」「办公」「工具」四个空文件夹。

此时启动器还没有任何应用。继续下一步即可。

> DesktopLauncher 是**单实例**程序。重复双击 exe 会弹窗提示「桌面启动器已经在运行了」，不会启动第二份。

## 2. 五分钟完成第一次整理

1. **打开启动器**：单击悬浮球，或按 `Ctrl+Alt+D`。
2. **进入编辑模式**：点右上角「✏ 编辑」，按钮变成「✓ 完成」。
3. **建分类**：点宫格末尾的「+ 新建文件夹」，输入名字（例如「设计」「影音」），回车。
4. **加应用**：点开一个文件夹 → 点「+ 添加应用」→ 在列表里勾选桌面上的快捷方式（可多选，也能用顶部输入框过滤）→「添加所选」。
5. **分好类**：回到主界面，按住应用磁贴拖到对应文件夹上松手；也可以在文件夹里右键应用 →「移入」。
6. **收工**：点「✓ 完成」退出编辑模式，按 `Esc` 收起启动器。以后单击悬浮球或按热键就能用了。

如果希望桌面本身也变干净，可以再开一个开关：[4.8 隐藏桌面图标](#48-隐藏与恢复桌面图标)。

## 3. 界面说明

### 3.1 悬浮球

悬浮球是一个 56×56 的半透明圆形按钮，常驻在所有窗口之上。

| 操作 | 效果 |
| --- | --- |
| 单击 | 打开 / 收起启动器 |
| 按住拖动 | 移动位置，松手后记住 |
| 拖到屏幕边缘附近松手 | 自动吸附到该边，只露出一条边 |
| 鼠标碰到露出的边 | 滑出来；移开约 0.7 秒后自动缩回 |
| 右键 | 「打开启动器 / 设置… / 隐藏悬浮球 / 退出」 |

- 拖动后位置写入配置，下次启动仍在原处；
- 换了显示器、分辨率变化导致位置越界时，会自动回到右侧默认位置；
- 启动器打开时悬浮球会被提到最上层，所以**再点一次悬浮球就能收起启动器**；
- 隐藏悬浮球不影响热键，之后可在托盘菜单里重新「显示悬浮球」。

### 3.2 全屏启动器

启动器覆盖**鼠标所在的那块屏幕**（多屏时不会跑到另一块屏上），由四部分组成：

| 区域 | 内容 |
| --- | --- |
| 顶部左侧 | 搜索框（提示文字「搜索应用…」） |
| 顶部右侧 | 「✏ 编辑」、「⚙ 设置」、「×」关闭 |
| 中间 | 分类文件夹宫格；搜索时切换为结果宫格 |
| 底部 | 操作提示（Toast），例如「已把 XX 移入「办公」」 |

- 背景是当前壁纸的模糊暗化版；使用纯色壁纸时显示深色渐变；
- 打开时有淡入和宫格上浮动画；
- 关闭方式：`Esc`、右上角 `×`、点击空白背景，或窗口失去焦点约 0.4 秒后自动收起；
- 如果是从后台（如开机自启）启动、窗口尚未获得过焦点，则不会因失焦自动关闭，避免「刚打开就消失」。

### 3.3 文件夹面板

单击文件夹磁贴，会在启动器中央弹出一个面板：

- 标题是文件夹名，右侧显示「N 个应用」；
- 面板里是该文件夹的应用宫格，末尾恒有一个「+ 添加应用」磁贴；
- 顶部按钮：`☐ 选择`（批量选择）、`✎ 重命名`（始终可用）、`+ 添加应用` / `🗑 删除`（仅编辑模式显示）、`×` 关闭；
- 点面板外的暗色遮罩或按 `Esc` 关闭面板（再按一次 `Esc` 关闭启动器）。

文件夹磁贴本身会预览**前 6 个**应用的图标（2 列 × 3 行）；应用多于 6 个时只显示前 6 个，不影响实际数量。

### 3.4 编辑模式与选择模式

两者都会让「点击磁贴 = 选中」而不是启动，并显示批量操作条，区别是入口和用途：

| | 编辑模式 | 选择模式 |
| --- | --- | --- |
| 入口 | 顶栏「✏ 编辑」 | 文件夹面板「☐ 选择」 |
| 退出 | 再点「✓ 完成」 | 再点「✓ 完成」 |
| 能力 | 新建 / 删除文件夹、单删应用、批量操作 | 只在当前文件夹内批量移动 / 移除 |

进入编辑模式后：

- 每个文件夹磁贴右上角出现 `×`（删除该文件夹）；
- 宫格末尾出现「+ 新建文件夹」磁贴；
- 每个应用磁贴右上角出现 `×`（从启动器移除该应用）；
- 选中应用后，面板底部批量条显示「已选 N 项」，可「移动到…」「移除所选」「取消选择」。

### 3.5 托盘菜单

右键托盘图标（双击托盘图标也可打开启动器）：

| 菜单项 | 说明 |
| --- | --- |
| 打开启动器 (Ctrl+Alt+D) | 等同于热键 |
| 显示悬浮球 | 勾选状态，控制悬浮球显隐 |
| 隐藏桌面应用图标 / 恢复桌面应用图标 | 随当前状态切换文字，见 [4.8](#48-隐藏与恢复桌面图标) |
| 开机自动启动 | 勾选即写入当前用户的启动项 |
| 设置… | 打开设置窗口 |
| 退出 | 退出程序（会保存配置） |

## 4. 功能详解

### 4.1 唤出启动器：悬浮球与全局热键

- **悬浮球**：单击开 / 关（再次单击收起）。
- **热键**：默认 `Ctrl+Alt+D`，任何时候都能用，包括悬浮球被隐藏时。
- **修改热键**：`设置 → 全局热键`，选择修饰键和主键后点「应用」。
  - 修饰键可选：`Ctrl+Alt`、`Ctrl+Shift`、`Alt+Shift`、`Ctrl+Alt+Shift`、`Win+Alt`；
  - 主键可选：`A`–`Z`、`0`–`9`、`SPACE`；
  - 成功时提示变绿并立即生效；被其他程序占用时提示变红，换一组即可。
- 热键注册失败不会影响其他功能，托盘会弹气泡提醒。

> 全屏游戏、远程桌面等场景可能独占键盘，热键在这些前台程序中不一定生效，这是 Windows 的限制。

### 4.2 新建、重命名、删除文件夹

**新建**（需编辑模式）：

1. 顶栏「✏ 编辑」；
2. 点宫格末尾的「+ 新建文件夹」；
3. 输入名称，回车或点「确定」。

名称不能与已有文件夹重名（不区分大小写），空名称会被忽略。

**重命名**（三种方式，效果相同）：

- 打开文件夹面板，点「✎ 重命名」；
- 打开文件夹面板后按 `F2`；
- 右键文件夹磁贴 →「✎ 重命名（F2）」。

**删除**（需编辑模式）：

- 文件夹磁贴右上角 `×`，或打开面板后点「🗑 删除」；
- 会弹出确认框，显示将有多少个应用退出启动器；
- **只删除这个分类，不删除任何文件**。

> 删除文件夹后，里面的应用不会再出现在启动器里，但仍留在配置中。想继续使用：打开任意文件夹 →「+ 添加应用」→ 找到显示「已添加」的那一行 → 点「移除」→ 再勾选它 →「添加所选」。
>
> 更稳妥的做法：删文件夹前，先把要保留的应用拖到别的文件夹。

### 4.3 添加应用

入口有两个：

- 打开任意文件夹面板，点末尾的「+ 添加应用」磁贴（任何模式都有）；
- 编辑模式下，文件夹面板右上角的「+ 添加应用」按钮。

「添加应用」窗口的内容：

| 区域 | 说明 |
| --- | --- |
| 顶部说明 | 提示不会移动原文件 |
| 过滤框 | 按名称或路径即时过滤 |
| 「浏览…」 | 打开文件选择框，可多选 `.exe` / `.lnk` / `.url`，选中后自动勾选 |
| 列表 | 已加入启动器的显示「已添加」+「移除」按钮；未加入的显示复选框，点整行切换勾选 |
| 底部 | 「已选 N 项」，以及「取消」「添加所选」 |

说明：

- 候选来自**用户桌面、公共桌面**，以及设置里配置的**额外扫描目录**；只扫描这三处的根目录，不递归子文件夹；
- 桌面路径通过注册表读取，所以桌面被重定向到 `D:\Desktop`、OneDrive 等位置也能正确识别；
- 同名（去掉扩展名后）的应用只保留一个，用户桌面优先于公共桌面；
- 同一个路径在启动器里只会有一条记录，不会重复添加；
- 添加成功后会回到该文件夹面板，并在后台预加载新图标。

> 同一应用只能属于一个文件夹。加入后想换分类，用拖拽或右键「移入」，不要重复添加。

### 4.4 移动与排序

**整组移动**：

- 按住应用磁贴，拖到某个文件夹磁贴上松手，即移入该文件夹（目标文件夹会高亮）；
- 或右键应用磁贴 →「移入「XX」」。

**文件夹内排序**：

- 在文件夹面板里，把应用拖到另一个应用磁贴上：
  - 落在目标磁贴的**左半**→ 插到它前面；
  - 落在**右半**→ 插到它后面；
- 排序结果立即保存，主界面文件夹磁贴的预览顺序也会同步变化。

**从启动器移除**：

- 右键应用磁贴 →「从启动器移除（不删文件）」；
- 或编辑模式下点磁贴右上角的 `×`；
- 只是删除配置记录，原始快捷方式 / exe 仍然在原处，随时可以重新添加。

拖拽使用系统的拖拽阈值，正常单击不会被误判为拖动；刚拖动结束的那一下也不会触发启动。

### 4.5 批量整理

在文件夹面板里点「☐ 选择」：

1. 点应用磁贴可多选 / 取消，选中的磁贴会高亮；
2. 底部出现「已选 N 项」和三个按钮：
   - **移动到…**：弹出文件夹列表，选一个目标，全部移过去；
   - **移除所选**：从启动器彻底移除这些应用（**所有**文件夹里的引用都会清掉，文件不受影响）；
   - **取消选择**：清空当前选择；
3. 点「✓ 完成」退出选择模式。

切换文件夹或进出编辑模式时，选择会自动清空。编辑模式下同样可以多选后批量操作。

### 4.6 启动应用

- 单击应用磁贴即可启动；
- `.lnk` / `.url` 交由 Windows Shell 打开，效果等同在桌面上双击（快捷方式里自带的参数、起始位置都会生效）；
- `.exe` 直接启动，可带配置中的参数与工作目录；
- 启动失败（文件被删除、路径变更、权限不足等）会在底部显示「启动失败：…」；
- 默认**启动后自动关闭启动器**，可在设置里关掉「启动应用后自动关闭启动器」。

> 需要管理员权限的程序（快捷方式属性里勾了「以管理员身份运行」）会照常弹 UAC，这是系统行为。

### 4.7 搜索

- 在顶部搜索框输入关键字，宫格立即切换为结果列表；
- 匹配范围：应用显示名，或文件名（不含扩展名），不区分大小写；
- 最多显示 40 条；
- 按 `Enter` 启动第一个结果；
- 清空输入框即恢复文件夹宫格；
- 搜索范围是**已经加入启动器的应用**；桌面上还没添加的程序请先「添加应用」。

### 4.8 隐藏与恢复桌面图标

这是唯一会改动桌面文件属性的功能，请先了解它的边界：

**它只做什么**

- 给**用户桌面**和**公共桌面根目录**下的 `.lnk`、`.exe`、`.url` 添加 Windows 的 `Hidden` 属性；
- 如果资源管理器当前是「显示隐藏的文件」，会临时切换为「不显示」，并记下原值；恢复图标时再改回去；
- 记录所有被处理的文件，供之后逐条恢复。

**它绝不做什么**

- 不移动、不重命名、不删除任何文件；
- 不碰文件夹、压缩包、文档、图片等非 `.lnk/.exe/.url` 文件；
- 不碰桌面子文件夹里的内容。

**隐藏**

- 托盘右键 →「隐藏桌面应用图标」；或 设置 → 勾选「隐藏桌面应用图标」；
- 完成后托盘气泡提示「已隐藏 N 个应用图标（文件夹与压缩包未动）」；公共桌面上因权限不足跳过的数量也会一并提示。

**恢复**

- 托盘右键 →「恢复桌面应用图标」；或 设置 → 取消勾选；
- 逐条去掉 `Hidden` 属性，文件已被删除的会跳过并清理记录；
- 恢复时会把你隐藏前的「显示隐藏文件」设置还原。

**注意**

- 隐藏后再往桌面放的新快捷方式不会被自动隐藏；先恢复、再隐藏一次即可；
- 桌面右键 →「查看 → 显示桌面图标」是系统级的整体开关，关掉后所有图标（包括未隐藏的）都不显示，与本功能无关；
- 卸载或重装系统前，**先恢复图标**，否则桌面上会少一批快捷方式（文件其实还在，只是带隐藏属性）。

### 4.9 文件夹快捷键

把常用目录绑到一组热键，按下直接用资源管理器打开：

1. `设置 → 文件夹快捷键 →「+ 添加文件夹快捷键」`；
2. 选择目录；
3. 新行默认使用 `Ctrl+Alt` + 一个未占用的键，可在行内直接改修饰键和主键；
4. 点行尾 `×` 删除该条。

- 支持多条，立即生效并保存；
- 键位与主热键、其他文件夹快捷键冲突时，设置窗口底部会用红字列出注册失败的组合；
- 目录被删除或改名后，按下热键不会做任何事（静默忽略）。

### 4.10 Windows 原生右键菜单

右键应用磁贴 →「Windows 菜单（复制 / 打开位置 / 压缩…）」，会在磁贴下方弹出与资源管理器一致的系统菜单，包含：

- 打开、复制、剪切、创建快捷方式、删除、重命名、属性；
- 「打开文件所在的位置」；
- 第三方 Shell 扩展（如 7-Zip 的「压缩到…」、Git 扩展等）。

菜单由系统 Shell 生成，所以第三方扩展是否出现取决于它自己。若调用失败，会提示「系统菜单不可用，可到资源管理器中操作」，不影响启动器其他功能。

> ⚠️ 这是**真正的系统菜单**：其中的「删除」会把文件删进回收站，而不是从启动器移除。只想把应用移出启动器，请用右键菜单里的「从启动器移除（不删文件）」。

### 4.11 托盘、开机自启与单实例

- 托盘图标常驻，双击打开 / 收起启动器；
- **开机自动启动**：托盘菜单勾选，或设置里勾选。写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，不需要管理员；
- 如果之后移动了 exe 的位置，开机自启仍指向旧路径，需要先取消再重新勾选；
- 单实例互斥体名为 `Local\DesktopLauncher_SingleInstance`，重复启动会提示。

### 4.12 设置项一览

| 设置 | 说明 |
| --- | --- |
| 全局热键 | 修饰键 + 主键，点「应用」后立即生效并保存 |
| 开机自动启动 | 写入 / 删除当前用户启动项 |
| 显示桌面悬浮球 | 立即显示 / 隐藏悬浮球 |
| 启动应用后自动关闭启动器 | 默认开启；关闭后启动器保持打开 |
| 隐藏桌面应用图标 | 见 [4.8](#48-隐藏与恢复桌面图标) |
| 文件夹快捷键 | 多条「目录 + 热键」，见 [4.9](#49-文件夹快捷键) |
| 额外扫描目录 | 让「添加应用」列表也扫描这些目录（如下载目录、旧桌面） |
| 完成 | 关闭设置窗口 |

### 4.13 个性化悬浮球

默认外观是蓝紫渐变的小球加四个白点。想换成自己的图片：

1. 准备一张正方形 PNG（建议 256×256，透明背景更好看）；
2. 命名为 `ball.png`，放到 `%APPDATA%\DesktopLauncher\`；
3. 重启 DesktopLauncher。

图片会按圆形裁剪显示。删除该文件即恢复默认外观。

## 6. 数据、备份与卸载

### 6.1 数据位置

| 文件 / 目录 | 内容 |
| --- | --- |
| `%APPDATA%\DesktopLauncher\config.json` | 全部分类、应用、悬浮球位置、热键、开关、额外目录、文件夹快捷键、隐藏图标清单 |
| `%APPDATA%\DesktopLauncher\icons\*.png` | 图标缓存（按路径哈希命名） |
| `%APPDATA%\DesktopLauncher\ball.png` | 可选的自定义悬浮球图片 |
| `%APPDATA%\DesktopLauncher\config.json.bak` | 配置损坏时自动留下的备份 |

`config.json` 是明文 JSON，可以直接查看。主要字段：

```json
{
  "Categories": [
    { "Id": "…", "Name": "常用", "AppIds": ["…"] }
  ],
  "Apps": [
    { "Id": "…", "Name": "记事本", "Path": "C:\\Users\\me\\Desktop\\记事本.lnk" }
  ],
  "BallX": -1,
  "BallY": -1,
  "BallVisible": true,
  "HotkeyModifiers": "Ctrl+Alt",
  "HotkeyKey": "D",
  "CloseOnLaunch": true,
  "ExtraScanDirs": [],
  "FolderHotkeys": [
    { "Path": "D:\\Work", "Modifiers": "Ctrl+Alt", "Key": "W" }
  ],
  "HideDesktopIconsEnabled": false,
  "HiddenIconPaths": []
}
```

手工编辑前请**先退出程序**，改完再启动；格式错误时程序会把旧文件备份为 `.bak` 并回到默认配置（分类会丢）。

### 6.2 备份与迁移

- 备份：托盘「退出」→ 复制整个 `%APPDATA%\DesktopLauncher\` 目录；
- 恢复：退出程序 → 用备份覆盖该目录 → 启动；
- 换电脑：配置里存的是**绝对路径**，换机后路径不同会导致条目失效，需要重新添加；同路径（同用户名、同盘符）可以直接用。

### 6.3 卸载

1. 托盘右键 →「恢复桌面应用图标」（如果开过隐藏）；
2. 托盘右键 → 取消「开机自动启动」；
3. 托盘「退出」；
4. 删除 `DesktopLauncher.exe`（或整个程序目录）；
5. 删除 `%APPDATA%\DesktopLauncher\`。

删除程序不会自动清除开机自启项，所以第 2 步不要省。

## 7. 常见问题

### 7.1 按热键没反应

- 组合可能被其他程序（截图、输入法、显卡驱动等）占用。打开设置换一组，成功时提示会变绿；
- 某些全屏游戏、远程桌面会独占键盘，热键在其中无效；
- 若托盘弹出过「全局热键注册失败」，说明启动时就冲突了，换绑即可。

### 7.2 桌面图标没有消失

按可能性排查：

1. 资源管理器开着「显示隐藏的文件」——本功能会临时切换为「不显示」，但如果之后又被别的软件改回来，图标会以淡化形式出现；重新执行一次隐藏即可；
2. 桌面右键 →「查看 → 显示桌面图标」被关掉了（这会让所有图标都不显示，不是本功能导致）；
3. 公共桌面上的图标权限不足，被跳过；气泡提示里会给出数量；
4. 只处理 `.lnk / .exe / .url`，文件夹、压缩包、文档本来就不会被隐藏；
5. 隐藏之后新放到桌面的快捷方式不会自动处理，需要再执行一次。

### 7.3 图标显示成灰色问号

说明图标提取不到：

- 快捷方式指向的程序被卸载、移动或删除；
- `.lnk` 的图标位置指向了不存在的文件；
- 图标缓存异常：退出程序，删除 `%APPDATA%\DesktopLauncher\icons\`，重启后会重建；
- 从启动器移除该条目，重新添加。

### 7.4 双击 exe 提示「已经在运行」

这是单实例保护。到托盘或悬浮球里找已经运行的实例，不要重复启动。如果托盘图标被 Windows 折叠，点任务栏的 `^` 展开。

### 7.5 启动器出现在另一块屏幕上

启动器固定在**鼠标所在屏幕**打开。想让它出现在副屏，先把鼠标移到副屏，再按热键或点悬浮球。

### 7.6 高 DPI 下界面模糊或错位

程序声明了 PerMonitorV2，会在目标屏幕上按实际 DPI 重算全屏尺寸。混合 DPI 多屏如果仍有异常，可尝试在 exe 属性 →「兼容性」→「更改高 DPI 设置」里交给系统缩放，或提交 Issue 说明屏幕配置。

### 7.7 启动器背景没有壁纸

纯色壁纸、动态壁纸、部分第三方壁纸软件不会提供静态图片，此时显示深色渐变属于正常回退。更换为图片壁纸后重新打开即可。

### 7.8 搜索不到桌面上的某个程序

搜索只覆盖**已加入启动器**的应用。先打开文件夹 →「+ 添加应用」把它加进来。桌面根目录没有的（例如开始菜单里的 UWP 应用）请用「浏览…」手动选择。

### 7.9 删掉文件夹后，里面的应用去哪了

文件当然还在桌面上，只是这个分类被删了，应用不再显示。找回方法见 [4.2](#42-新建重命名删除文件夹) 的提示：在「添加应用」里把它「移除」再重新勾选添加。

### 7.10 安全软件报毒

单文件自解压 exe 是常见误报来源（程序会把运行时释放到临时目录）。可以：

- 将 exe 加入信任；
- 或者改用非单文件发布：`dotnet publish DesktopLauncher -c Release -r win-x64 --self-contained true -o publish`；
- 或者直接从源码构建。

程序没有网络行为，也不修改系统设置（除开机自启和「显示隐藏文件」开关，后者隐藏结束会还原）。

### 7.11 开机自启没有生效

- 检查托盘菜单里「开机自动启动」是否仍勾选；
- 安全软件可能拦截了写启动项；
- 移动过 exe 位置会导致旧路径失效：取消勾选再重新勾选；
- 可手动检查 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `DesktopLauncher` 值。

### 7.12 悬浮球不见了

- 托盘菜单 →「显示悬浮球」；
- 或按热键打开启动器 →「⚙ 设置」→ 勾选「显示桌面悬浮球」；
- 换过显示器导致位置越界时，重启程序会回到默认位置。

### 7.13 文件夹快捷键冲突

设置窗口底部会红字列出注册失败的组合。换一个键位，或删掉不用的条目。主热键与文件夹快捷键共用同一套注册表空间。

## 8. 调试与二次开发

### 8.1 构建

```bash
dotnet build DesktopLauncher -c Release
dotnet run --project DesktopLauncher -c Release
```

项目目标框架 `net10.0-windows`，使用 WPF；WinForms 仅用于托盘图标和文件夹选择框。没有第三方 NuGet 依赖。

### 8.2 启动参数

以下参数主要供开发自测，普通使用不需要：

| 参数 | 作用 |
| --- | --- |
| `--show` | 启动后立即打开启动器 |
| `--popup=<分类Id>` | 打开指定分类的面板；不带 Id 时打开第一个非空分类 |
| `--popup --edit` | 以选择态打开面板，2 秒后把界面渲染成 `edit_dump.png` 并退出 |
| `--addapp` | 启动后弹出「添加应用」窗口，6 秒后退出 |
| `--settings` | 打开设置窗口，2 秒后导出 `settings_dump.png` 并退出 |
| `--dockball` | 把悬浮球贴到右边缘，验证贴边动画，4 秒后退出 |
| `--hideicons` / `--showicons` | 隐藏 / 恢复桌面图标后退出，结果写入 `hide_result.txt` |
| `--icontest=<文件>` | 提取指定文件的图标存为 `test_icon.png`，并写诊断文本 `test_diag.txt` |
| `--shellmenu=<文件>` | 诊断原生右键菜单的 COM 链路，结果写入 `shell_diag.txt` |

上述文件都输出到 `%APPDATA%\DesktopLauncher\`。

### 8.3 代码结构

| 目录 | 职责 |
| --- | --- |
| `Models/` | `AppConfig`、`Category`、`AppEntry`、`FolderHotkey` 数据模型 |
| `Services/DesktopPathResolver` | 从注册表 `User Shell Folders` 解析真实桌面路径 |
| `Services/AppScanner` | 扫描桌面 / 公共桌面 / 额外目录的 `.lnk/.exe/.url` |
| `Services/LnkParser` | 用 `WScript.Shell` 解析快捷方式目标与图标位置 |
| `Services/IconService` | `PrivateExtractIcons` 提取图标，内存 + PNG 磁盘两级缓存 |
| `Services/WallpaperService` | 读取壁纸，缩小再放大做低成本模糊 |
| `Services/HotkeyService` | 隐藏消息窗口 + `RegisterHotKey`，主热键与文件夹热键 |
| `Services/LaunchService` | `Process.Start` 启动，`.exe` 支持参数与工作目录 |
| `Services/ConfigStore` | JSON 读写 `%APPDATA%\DesktopLauncher\config.json` |
| `Services/DesktopIconHider` | 桌面图标隐藏 / 恢复与清单管理 |
| `Services/ExplorerSettings` | 读写资源管理器「显示隐藏文件」并广播刷新 |
| `Services/ShellContextMenu` | `IShellFolder` / `IContextMenu` 原生菜单 |
| `UI/LauncherWindow` | 全屏启动器：宫格、文件夹面板、搜索、编辑、拖拽、批量 |
| `UI/FloatingBallWindow` | 悬浮球：拖动、贴边、滑出、自定义外观 |
| `UI/TrayController` | 托盘图标与菜单、开机自启 |
| `UI/Dialogs/` | 添加应用、输入框、设置 |

### 8.4 二次开发提示

- 所有界面元素都是代码动态构建（磁贴、菜单），改布局主要看 `LauncherWindow.xaml.cs`；
- 图标缓存 key 是路径小写后的 SHA-256 前 16 位，换图标需清缓存；
- 配置保存是「全量写 JSON」，没有数据库，适合直接加字段（旧配置缺少字段时用默认值）；
- 单实例互斥体在 `App.OnStartup`，调试多开时注意先退出已有实例。

## 9. 设计取舍与已知限制

- **只支持 Windows 10/11**，依赖 WPF、WinForms 托盘、Win32 Shell API；
- **界面仅简体中文**；
- **不做文件管理**：不搬移、不删除、不重命名桌面文件；图标隐藏只是临时属性，可还原；
- **只索引桌面根目录**（加额外目录），不递归子文件夹；
- **不接管开始菜单 / Win 键**，也不替换系统桌面；
- **无云同步、无自动更新**，配置只在本机；
- **应用条目存绝对路径**，目标被移动/卸载后会失效，需要移除重加；
- **图标缓存不会自动过期**，换图标后需手动清理；
- **原生右键菜单**依赖系统 Shell 与第三方扩展，个别扩展可能不显示；
- 删除文件夹、批量移除等操作立即写入配置，**没有撤销**；重要整理前建议备份 `config.json`。
